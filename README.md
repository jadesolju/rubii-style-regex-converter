# Regex Studio

เว็บเรียน Regex ภาษาไทยสำหรับคนที่อยากตกแต่งข้อความในแอปแชต Rubii โดยไม่ต้องมีพื้นฐานมาก่อน ประกอบด้วยคู่มือ 17 บท ห้องทดลองสูตร คลังสูตรสำเร็จรูป และ API สำหรับนักพัฒนา

สถานะ: รันในเครื่องได้ ยังไม่เปิดรับ public traffic

## ในเว็บมีอะไร

| ส่วน | ใช้ทำอะไร |
| --- | --- |
| หมวดหมู่เริ่มต้น | หน้าแรก รวมสูตรแกนหลักที่ใช้บ่อยไว้ในที่เดียว |
| บทเรียน (17 บท) | เรียงจากศูนย์ไปจนถึงการใช้งานกับแชต เปิดอ่านทีละบทในหน้าเต็ม แต่ละบทมีส่วน "บทนี้พูดถึงอะไร" บอกเป้าหมาย คำศัพท์ และบทที่ควรอ่านมาก่อน |
| ห้องทดลอง (Sandbox) | พิมพ์สูตรและข้อความ ดูผลที่ตรงกัน กลุ่มจับ และผลหลังแทนที่ พร้อมอธิบาย Flags แยกสี |
| คลังสูตร (43 สูตร) | สูตรพร้อมใช้ที่ตรวจตัวอย่างอัตโนมัติ |
| Cookbook (10 ชุด) | ชุดกฎและสไตล์ที่ส่งออกไปใช้ในแอปได้ทันที |

เนื้อหาบทเรียนอยู่ระหว่างปรับเป็นภาษาเล่าให้อ่านง่ายขึ้น ตอนนี้บทที่ 1 ถึง 4 เขียนใหม่แล้ว ส่วนบทที่ 5 ถึง 17 ยังเป็นฉบับเดิมและจะทยอยปรับต่อ

## เริ่มต้นใช้งาน

ต้องมี Node.js 24 LTS (รุ่น 24 เท่านั้น) และ npm จากนั้นรัน:

```sh
npm install
npm run dev
```

เปิดเบราว์เซอร์ที่ `http://localhost:3000` พอร์ตและที่อยู่ตั้งได้ในไฟล์ `.env` (ดูตัวอย่างใน `.env.example`)

| คำสั่ง | หน้าที่ |
| --- | --- |
| `npm run dev` | เริ่มเซิร์ฟเวอร์สำหรับพัฒนา |
| `npm test` | รันชุดทดสอบ (17 รายการ) |
| `npm run typecheck` | ตรวจชนิดข้อมูล TypeScript |
| `npm run build` | คอมไพล์ไปที่ `dist/` |
| `npm start` | รันจากโฟลเดอร์ `dist/` หลัง build |

## API

เซิร์ฟเวอร์ให้บริการทั้งหน้าเว็บและ API ในที่เดียว ดูสัญญา API ฉบับเต็มได้ที่ `/v1/openapi.json`

| Endpoint | หน้าที่ |
| --- | --- |
| `GET /healthz` | ตรวจสถานะเซิร์ฟเวอร์ |
| `GET /v1/lessons` และ `/v1/lessons/{id}` | รายการและรายละเอียดบทเรียน กรองด้วย `q`, `category`, `level`, `locale`, `audience` |
| `GET /v1/patterns` และ `/v1/patterns/{id}` | คลังสูตร |
| `GET /v1/recipes` และ `/v1/recipes/{id}` | ชุดสูตรสำเร็จรูป |
| `GET /v1/recipes/{id}/export` | ส่งออกชุดสูตรเพื่อนำไปใช้ต่อ |
| `POST /v1/regex/test` | ทดสอบสูตรกับข้อความ ได้ผลที่ตรงกัน กลุ่มจับ และข้อความหลังแทนที่ |

ตัวทดสอบ Regex ทำงานในตัวประมวลผลแยก มีกำหนดเวลาสูงสุดและจำกัดขนาดข้อมูล เพื่อกันสูตรที่ทำให้ค้าง

## โครงสร้างโปรเจกต์

```text
content/   ข้อมูลเนื้อหาเป็น JSON (lessons, patterns, recipes, styles, sources)
public/    หน้าเว็บ (index.html), cookbook.js และรูปภาพ
src/       เซิร์ฟเวอร์ Fastify, ตัวตรวจเนื้อหา, ตัวทดสอบ Regex
test/      ชุดทดสอบ
docs/      เอกสารแผนและตำรา
```

ตอนเริ่มเซิร์ฟเวอร์ ระบบจะตรวจเนื้อหาทั้งหมดว่า reference ครบ สูตร Regex คอมไพล์ได้ และชุดสูตรอ้างถึงของที่มีอยู่จริง

## ข้อตกลง

- เอกสารแผนและข้อสรุปเก็บเป็น Markdown
- เนื้อหาที่ API ใช้เก็บเป็น JSON และตรวจ reference ตอนเริ่มระบบ
- ไม่บันทึกข้อมูลสำคัญในเครื่อง ข้อมูลรับรอง หรือรายละเอียดสภาพแวดล้อมส่วนตัว
- ชื่อฟิลด์และรายละเอียดใน API เป็นข้อเสนอของโครงการ ไม่ใช่ API หรือ schema ทางการของ Rubii
- API ยังไม่มี authentication หรือโควตา จึงตั้งค่าให้รับคำขอจากเครื่องนี้เท่านั้น
